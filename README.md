# AIBMDD
<br><b>AI-Based Models in Drug Discovery (1st Edition)</b></br>
<br> </br>
Editor: Prof. Walter Filgueira de Azevedo, Jr.
Proposed date: January 31, 2027. 
<br> </br>
Computational methodologies in drug discovery have advanced in step with computer power [1–3]. Even as the predicted end of Moore’s Law [4,5] suggests a slowdown, the adoption of new technologies continues to boost computational capabilities [6]. This improvement directly enhances the role of computational techniques in the search for new drugs [7–11]. 
Concomitantly, we witness a great evolution of data related to protein targets and receptor-ligand affinity data. We have over 250,000 experimental structures in the Protein Data Bank (PDB) [12–19]. These experimental structures define a limited area of the protein structure space. The success of deep learning techniques in building three-dimensional models of protein structures enlarges the area of the protein structure space available for drug discovery projects [20–22]. Additionally, binding databases [23–25] provide receptor-ligand affinity data fully integrated with structural data. Thanks to these developments, we have an ideal scenario for AI development to address protein-ligand interactions. We can integrate binding and structural data to train AI models to predict affinity based on atomic coordinates.
With this in mind, we prepared this book on AI models built to address protein-drug interactions. Here we have state-of-the-art techniques focused on protein-ligand interactions. We describe the most recent developments of the scoring functions available in the docking program AutoDock Vina [26]. We explore the scoring function space concept [27–30] to build AI models to predict binding affinity based on the atomic coordinates of protein-ligand complexes. 
The scoring function space concept integrates the chemical and protein spaces. This abstraction incorporates systems biology approaches to drug discovery. We explore the flexibility of the Scikit-Learn library [31] and PyTorch [32] to develop AI models. Scikit-Learn is an open-source library of multiple regression methods integrated into Python tools such as SAnDReS (Statistical Analysis of Docking Results and Scoring Functions) [33] and Taba (Tool to Analyze Binding Affinity) [34]. PyTorch focuses on deep learning methods such as Feedforward Neural Networks (FFNNs) and Recurrent Neural Networks (RNNs). 
The spectrum of regression methods in Scikit-Learn and PyTorch libraries opens the possibility of exploring the scoring function space. We may try different AI approaches to find an adequate model for a protein system of interest. We have chapters devoted to ensemble methods (e.g., bagging meta-estimator) and deep learning techniques (e.g., RNNs).
We explain all methods and provide tutorials. In these tutorials, we focused on drug targets [35-38]. For all these protein targets, we have structural and binding affinity data. This integration of biological data and state-of-the-art AI techniques navigates an interdisciplinary environment focused on real-life problems. Another milestone of this volume is the application of open-source programs such as SAnDReS [33] and Taba [34] to generate AI models for predicting the binding affinity against protein targets of interest. These programs rely on the scoring function space concept to find an adequate computational model [39–41]. With this approach, we abandon universal scoring functions [27]. SAnDReS and Taba generate machine-learning models targeted to one protein system, which we expect will outperform classical scoring functions [26].  
All this progress brings us new possibilities for developing high-accuracy models for one protein. We expect a rise in the AI-based models to calculate binding affinity, making it feasible to have a scoring function database (SFDB). This SFDB will store previously developed scoring functions that can be used to predict the affinity for experimental structures obtained using X-ray diffraction crystallography, nuclear magnetic resonance (NMR) spectroscopy, or cryo-electron microscopy (Cryo-EM). We adopt a hands-on approach in the tutorials described in this volume, exploring the exciting field of AI applied to drug discovery. All input data files and Jupyter Notebooks necessary to run the tutorials presented here are freely available on GitHub (https://github.com/azevedolab/). All discussed codes are easily modified to generate AI-based models for any protein target for which structural and binding data are available.
